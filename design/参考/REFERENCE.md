**共性（移动财务 UI 的"最小公共集"）**
- 表面：近白或浅灰底 + 白卡；**一个信任色**（绿/蓝）+ 1–2 个状态色；无重阴影。
- 数字：**大数字 + 小标签 + 辅助灰行**；金额右对齐、tabular；"还剩 / 覆盖 / 占比"都有明确主语。
- 关系表达：进度条、环形、瀑布/趋势线；**不做成装饰插画**。
- 结构：分段 tabs（Reports / Budget / 分类）+ 列表行 + 卡片区块；行高约 56–64。
- 状态：主按钮/次按钮、pending 标记、免责脚注、空态。
- 文案：短句、口语化、动词开头（"See where every dollar flows"）。

## 三、对我们（myDca · 配置仪表）的结论

1. **我们是"管理工具 + 移动财务"的交叉**：取移动财务的"数字与结构表达"，取管理工具的"配色纪律与克制"。
2. **弱主视觉、强信息**：首屏由"一个总资产 + 一个配置结构 + 6 支状态"构成，不设海报式 hero。
3. **只有一个信任色 + 一个状态色**：绿系（品牌"种树"）做信任与正向；状态色只用于涨跌/警示。
4. **配置的表达**照 有知有行/且慢 学：占比列表 + 环形/条形 + "目标 vs 当前"的偏离；但**不做销售 CTA**。
5. **待处理/状态**照 Copilot 学：把"待收分红、待核对、到期定投"做成可操作卡片。
6. **明确排除**：纸张/账本/刊物/报纸/表格主线、设备包装、营销渐变、促销浮层、社区流。

## 四、三套主题假设（同一信息结构 × 3 主题；Step 2 出图对象）

> 结构固定：顶栏（总资产 + 今年收益切换）→ 配置结构（占比/偏离）→ 覆盖/现金流 → 6 支持仓列表 → 底部 tab。
> 只变：颜色、字体、圆角、密度、图表语气。

| | T1 安静白 + 墨绿（最稳） | T2 暖白 + 深绿/铜（最有温度） | T3 深色 chrome + 浅内容（最克制） |
|---|---|---|---|
| 参考 | Monarch 表面 + 有知结构 | 视频示例"暖白 + 墨绿重点" | Linear 的克制（只借 chrome） |
| 表面 | `#FAFAF8` 近白，白卡，1px 浅边 | `#F7F4EC` 暖白，白卡，无纹理 | 顶栏/底栏 `#14181A`，内容区 `#F7F7F5` |
| 主色 | `#2E6B4F` 墨绿 | `#1F4D3A` 深绿 + `#A8763E` 铜 | 深绿 `#2E6B4F` + 单一 accent |
| 数字 | 近黑 `#141614`，大而重，tabular | 墨绿黑 `#1C2A22` | 近黑，数字更大 |
| 圆角 | 16 | 12（更收敛） | 12 |
| 风险 | 易像通用理财 App，要靠"配置偏离"拉开差异 | **必须无衬线、无纹理、无横线**，否则滑向账本/纸张 | 用户曾反馈深色偏黑 → 只做 chrome，不做全屏深色 |

## 五、主题要配置的组件清单（定组件库时按这个验）

1. 顶栏 / 页面标题 2. 大数字卡（金额 + 变化）3. 分段 Tabs 4. 占比条 / 环形图 5. 进度指标（覆盖）6. 列表行（名称/代码/数值/涨跌）7. 状态 pill 8. 主/次按钮 9. 底部 Tab Bar 10. 空态 / 加载 / 错误 11. Toast / 弹层 12. 免责与更新时间脚注

## 六、Step 2 出图要求（给图像工具；用户已有出图工具）

每套主题单独出图（不要拼一张）；输入 = **现有信息结构截图（或本参考板的页面结构） + 本主题参考截图 + 文字方案**。硬要求：

- 画面像**正对屏幕截下来的网页/App**；**不要手机/电脑模型、不要斜着摆的展示板、不要灯光包装**；
- **保留页面的信息与操作结构，不新增功能**；管理工具**不要强主视觉**；表格/列表**不要画成艺术海报**；
- 只用一套组件语言（圆角/间距/按钮/图表一致）；正文与表格文字必须清晰，**不允许淡到看不清**；
- 三张图只变主题（颜色/字体/圆角/密度），结构一致，便于对比"表达方式"而不是"哪个颜色好看"。
