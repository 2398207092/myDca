# 首页动效标注表（给开发；不进生图 AI）

> 对应结构：方案 B「三锚点 + 抽屉收纳」**作为格式载体**（结构本身仍待确认，选 A/C 则本表重写）。
> 帧图：`帧图/帧A-首屏.png`（初始）、`帧图/帧B-持仓抽屉.png`（第二状态）。
> 规则：每个动效必须回答"它让什么变清楚"；无动效时信息仍完整可读；全部尊重 `prefers-reduced-motion`（降级为直接切换）。

## 1. 总资产卡

| 项 | 内容 |
|---|---|
| 触发 | 点按整张卡 |
| 对象 | 数字 + 标签（总资产 ⇄ 今年收益） |
| 帧 A → 帧 A' | `¥128,640 / 总资产` → `+6,480 / 今年收益` |
| 顺序与时长 | 标签先换 60ms，数字 crossfade 150ms；整卡无位移 |
| 目的 | 同一锚点回答两个问题，避免第二个大数字抢层级 |
| 降级 | 直接切换（无淡入） |
| 强度 | 轻 |

## 2. 配置卡（环形 + 占比）

| 项 | 内容 |
|---|---|
| 触发 | 点按配置卡 |
| 对象 | 环形图 + 占比行 + 目标偏离 |
| 帧 A → 帧 C（配置明细抽屉） | 首屏环形静置 → 抽屉展开：5 段占比逐行列出 + "目标 vs 当前"偏离 + 5 段环逐段高亮 |
| 顺序与时长 | 抽屉升起 240ms（`cubic-bezier(.2,.8,.2,1)`）；环 5 段依次高亮，每段 60ms |
| 目的 | 把"配置对不对"从一句结论展开成可核对的明细 |
| 降级 | 抽屉直接出现；环静态高亮 |
| 强度 | 中 |

## 3. 分红覆盖

| 项 | 内容 |
|---|---|
| 触发 | 点按覆盖卡 |
| 对象 | 进度条 + 2/5 + "再攒 ¥680" |
| 帧 A → 帧 D（覆盖明细抽屉） | 首屏 40% 进度 → 抽屉：5 项生活支出（已覆盖/奋斗中/待点亮）逐项列出 |
| 顺序与时长 | 同配置抽屉；进度条从 0 生长到 40%（400ms，仅首次加载） |
| 目的 | 把"2/5"变成可行动的清单（差 ¥680 点亮哪一项） |
| 降级 | 直接显示 40% 与清单 |
| 强度 | 中 |

## 4. 持仓入口 → 6 支列表抽屉

| 项 | 内容 |
|---|---|
| 触发 | 点"查看全部 6 支 →"或上滑抽屉入口 |
| 对象 | 底部抽屉（占屏约 66%） |
| 帧 A → 帧 B | 首屏（前 3 支预览）→ 抽屉升起，完整 6 支；背景遮罩 28% 变暗 |
| 顺序与时长 | 抽屉 240ms 升起 + 遮罩 200ms 淡入；下拉/点遮罩关闭（回弹 200ms） |
| 目的 | 首屏保持三锚点清爽，6 支细节按需出现，不牺牲可查性 |
| 降级 | 抽屉无动画直接出现；手势关闭改为关闭按钮 |
| 强度 | 中（重点手感：跟手拖拽、松手按速度决定开/关） |

## 5. 持仓行展开

| 项 | 内容 |
|---|---|
| 触发 | 抽屉内点任一行 |
| 对象 | 该行下方展开成本 / 年分红 / 仓位 |
| 顺序与时长 | 高度过渡 180ms；同时只允许一行展开（点另一行先收起上一行） |
| 目的 | 详情就地读，不跳页 |
| 降级 | 直接显示/隐藏 |
| 强度 | 轻 |

## 6. 底部 tab

| 项 | 内容 |
|---|---|
| 触发 | 点 tab |
| 对象 | 选中态 + 页面内容 |
| 顺序与时长 | 图标/文字换色 120ms；页面切换用系统级过渡（不自定义大动效） |
| 目的 | 明确当前位置 |
| 降级 | 颜色直接切换 |
| 强度 | 轻 |

## 7. 入场（整页一次）

| 项 | 内容 |
|---|---|
| 触发 | 首次进入页面（或从后台回前台） |
| 对象 | 总资产数字 + 配置环 + 覆盖进度条 |
| 顺序与时长 | 数字 0→128,640（100 步进，900ms）→ 环形绘制 400ms → 覆盖条生长 400ms；只发生一次 |
| 目的 | 建立"这是一页读数"的第一印象；不做逐块 fade-up |
| 降级 | 全部直接呈现终值 |
| 强度 | 中（整页唯一一次编排） |

## 8. 轻 3D（可选，默认关闭）

| 项 | 内容 |
|---|---|
| 触发 | 滚动 / 下拉时（仅总资产卡） |
| 对象 | 总资产卡 1–2° 透视倾斜 + 阴影位移；长按持仓卡轻浮起 2–3px |
| 顺序与时长 | 跟手 + 回弹 200ms；不做翻转、不做全景 3D |
| 目的 | 给"卡片是实体"的触感，不承载信息 |
| 降级 | 完全移除；不影响任何信息 |
| 强度 | 轻（若做，必须可用开关关闭） |

## 不在本表的东西

- 具体缓动曲线、时长数值、弹簧参数 → 开发阶段定 motion tokens。
- 颜色/字体/圆角/阴影 → 属于四套主题（T1–T4），不是动效。
- 生图 AI 不需要本表；它只需要 `帧A` / `帧B` 两张参考图 + 主题提示词。
