> 方法依据：B 站 `BV1dsaw62EWy`。四套主题**共用同一信息结构**，只换视觉；每套单独出一张（不要拼图）。
> 出图时附两张图：**附图 1 = `帧图/帧A-首屏.png`**（必须严格保持布局）；**附图 2 = `帧图/帧B-持仓抽屉.png`**（同一页面的第二状态，只作对照，不改变主题与主结构）。

## 0. 通用提示词（每套都在最前面粘这段）

```

不要手机/电脑模型，不要斜放、不要透视、不要外部灯光与桌面背景，不要营销文案、logo 墙、标题说明、水印、边框。
界面文字全部用中文，数字用等宽数字对齐；信息必须清晰可读，正文与标签对比度足够，不能淡到看不清。
严格保持附图 1 的布局与信息层级，不新增功能、不删减条目、不移动模块顺序：
1) 顶部：品牌标识 + 同步时间；
2) 总资产大数字（¥128,640）+ 辅助行（持仓 ¥96,180、现金 ¥32,460、今年 +5.3%）；整卡可点按切换“今年收益”；

这是“管理工具”页面，不是海报：弱主视觉、强信息结构；图表与列表不要艺术化，不要做成杂志/报纸/账本/三线表。
```

## T1 安静白 + 墨绿（最稳）

```
风格：安静、可信、清透的现代资产管理工具。
背景 #FAFAF8，卡片 #FFFFFF，主文字 #141614，次级文字 #6B7280，主色墨绿 #2E6B4F（用于选中态、进度条、关键数字强调），辅助色浅灰 #E5E7EB；
卡片圆角 16px，1px 极浅描边 rgba(20,22,20,.06)，几乎不用阴影；分割靠留白与浅描边，不要通栏横线；
数字用无衬线等宽、字号大而重；标签小一号；环形图用 5 段低饱和绿/暖灰色，无渐变；底部 tab 选中用墨绿。
整体一屏信息完整、呼吸感足够，不要装饰插画。
```

## T2 暖白 + 深绿 / 铜（最有温度）

```
风格：温暖、可靠、克制的私人资产感，但绝不能像纸张或账本。
背景 #F7F4EC，卡片 #FFFDF8，主文字 #1C2A22，主色深绿 #1F4D3A，强调铜色 #A8763E 只用于小面积（选中标记、关键数字下划线、图标），次级文字 #6B7280；
圆角 12px，无纹理、无纸张肌理、无印章、无衬线标题、无通栏横线；分割只在必要处用 1px 极浅线；
字体全部无衬线（中文思源黑体/苹方观感），数字加粗等宽；环形图 5 段暖色系但低饱和；底部 tab 用深绿文字。
氛围温暖但信息密度不降，不要做成手账或复古纸张。
```

## T3 深色 chrome + 浅内容（最克制）

```
风格：克制的专业工具，深色只用于“外壳”，内容区保持浅色。
顶栏与底部 tab 深色 #14181A（白色文字），内容区 #F7F7F5，卡片 #FFFFFF，主文字 #16181D，主色墨绿 #2E6B4F，单一强调色暖金 #D9A441 只用于一条关键线或两个关键数字；
圆角 12px，1px 浅描边，浅阴影；不要全屏深色、不要霓虹、不要发光；
数字无衬线等宽、层级强烈；环形图用墨绿单色深浅 5 段；tab 选中为暖金小点。
整体像高级数据分析工具，而不是开发者 IDE。
```

## T4 新拟态 Neumorphism（严格限定在可操作控件）

> 依据 spicytater.cn「新拟态」：把触感留给真正的操作；阴影只表达表面关系，**不能替代标签、状态、错误与焦点指示**；最大的坑是所有元素同色导致分不清按钮与背景。

```
风格：新拟态（Neumorphism），但严格限定在“可操作控件”上。
底色与卡片同为 #E7EAEF 单色系表面；可交互控件（总资产卡点按态、配置环形、进度条、持仓入口、底部 tab、主按钮）用“左上柔光 + 右下柔影”的双向阴影轻轻凸起，按下态轻微压入；圆角 14–18px。
主色 #2E6B4F（或 #3B5B9E）只用于按钮文字/选中指示，保持克制；
信息文字与数字保持平面、深色高对比（#1B2430），不要给文字加浮雕阴影；
配置占比列表、持仓列表保持平面清晰，不要整页所有元素都做成同色凸起软块；
不要玩具 3D、不要大浮雕、不要低对比灰字；标签、状态文字（覆盖 2/5、目标偏离、涨跌幅）必须清楚可读。
整体：安静、有触感的操作反馈，但首先是能读数据的工具。
```

## 出图后怎么用

1. 四套各出一张，命名 `T1.png` / `T2.png` / `T3.png` / `T4.png`，放 `design/概念/` 或直接发我。
2. 我按视频的“拆解开发”标准评审：信息完整、是否海报化、组件可落地、文字可读性、390 密度。
3. 选定一套 → 定组件库（PrimeVue / Naive UI / Ant Design Vue / Element Plus 评估）→ 主题配置实现 → 真实页面 390/320 验证。
