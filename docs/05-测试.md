# 05 · 测试

> 最后核实：2026-10-27

手机端 UI 改动后的三层检查。**能自动断言的都断言，截图只用于判断"看起来对不对"。**

---

## 一、三层检查

| 层 | 手段 | 抓什么 | 不抓什么 |
|---|---|---|---|
| **L1 自动断言** | `scripts/ui-check.cjs`（Playwright + 系统 Chrome） | 默认标记数量、金额格式、文字重复、底部遮挡、控制台报错 | 视觉美感、文案是否拗口 |
| **L2 视觉评审** | 截图 + `ViewImage`，按下方清单逐条看 | 层级混乱、拥挤、截断、空状态占地 | 精确像素、交互逻辑 |
| **L3 契约检查** | `scripts/api-contract-check.cjs` | 字段名/类型不一致（如 `isDefault` vs `default`） | 业务语义、视觉 |

一键跑完三个：`bash scripts/check-all.sh`

三层缺一不可。2026-10-27 的实例：L3 能抓到 `isDefault` 序列化错名，L2 能抓到「现金 现金」重复，L1 能抓到「万/元混排」——三者互不替代。

## 五、契约检查（L3）

脚本：`scripts/api-contract-check.cjs`。对每个接口声明「必须有这些字段、类型是什么」，字段缺失或类型不对即失败。

```bash
TOKEN=$(cat /tmp/token.txt) node scripts/api-contract-check.cjs
```

写法（在脚本的 `CONTRACTS` 数组里加一项）：

```js
{
  name: '账户列表 GET /api/accounts',
  path: '/api/accounts',
  shape: 'array',
  fields: { id: 'string', isDefault: 'boolean', totalValueCny: 'number', assets: 'array' },
  forbidden: ['default'],   // 捕获 Jackson 把 isDefault 序列化成 default 的坑
}
```

三条规则：
- **boolean 字段必须 `isXxx`**：后端 DTO 要加 `@JsonProperty("isXxx")`，否则 JSON 里会掉 `is`
- **允许 null 的字段写 `'string|null'`**，不要写成 `'string'`
- **`forbidden` 用来防回归**：把曾经错过的字段名写进去，再犯就直接红

**怎么确认断言有效**：把某个字段名故意改错（如 `isDefault` → `isDefaultXX`）跑一次，必须 FAIL；改回后 PASS。不做这一步，等于不知道它有没有在工作。

## 六、已捕获的真实问题（作为用例）

| 问题 | 哪一层抓到 | 修法 |
|---|---|---|
| 账户无「默认」标签、每个账户都显示「设为默认」 | L3（字段名） + L2（截图） | DTO 加 `@JsonProperty("isDefault")` |
| 金额 `¥5.94万` 与 `¥5755.78` 混排 | L1（断言 3/4） | 账户区统一 `fmtExact` |
| 「现金 现金」名与类型重复 | L1（断言 5） + L2 | 类型标签与名称相同时不渲染 |
| 空账户占据整张卡片 | L2 | 空账户沉底 + 压缩为空行 |
| 多个账户同时 `is_default=1` | L1（断言 2） + 数据库核对 | 读取时 `normalizeDefaults` 收敛为 1 个 |

## 七、这套流程的设计原则

1. **能断言的不要靠看**：人眼会漏、会疲劳，脚本不会。但断言写错会"假通过"，比失败更危险。
2. **断言必须限定作用域**：扫全页找「万」，会被总资产里的「万」掩盖账户区的问题。第一版就栽在这里。
3. **截图用真实引擎 + 真实数据 + 真机视口**：390×844 + 移动 UA，不用桌面窗口缩放模拟。
4. **每个 bug 变成一条断言**：修完立刻补断言，下次同样的错不会再溜过去。
5. **修完必须重跑，直到全绿**：不允许"应该好了"这种判断。
6. **脚本要能失败**：故意注入错误（改字段名、去掉默认标签）验证断言真的会红，否则等于没测。

## 八、扩展方式

新增断言只需在 `scripts/ui-check.cjs` 里加一个 `check(名称, 布尔值, 详情)`。
新增页面检查时，复制「发现页」段落的导航 + 截图 + 断言结构即可。

> 注意：断言必须**限定作用域**（如 `accountBlock`），否则会像第一版那样把全页金额算进来，出现"假通过"。
