## 五、五条硬规则

1. **一次只用一家**：同一任务不叠加两个技能；设计评审（impeccable）与规范审计（web-design-guidelines）分开跑。
2. **技能是顾问**：产出是报告/建议，先给用户看；采纳后再改代码，且不引入依赖/组件库/配色皮肤。
3. **不写第二真相源**：`init` / `document` / `extract` / `--persist` 默认禁用；任何技能要写 `PRODUCT.md`、`DESIGN.md`、`.impeccable/`、`design-system/` 到仓库，先经用户同意，否则输出到 `.workbuddy/tmp/`。
4. **冲突以项目为准**：`design/00-基准.md`、三套皮肤互不污染、改 UI 必须真实截图（390/320、0 console、0 横向溢出）。
5. **排除旧隐喻**：技能数据里出现「账本 / 纸张 / 刊物 / 编辑风格」（如 `data/styles.csv` 的 E-Ink/Paper、Editorial Grid）时直接排除，不得推荐。
