# 年化收益率（IRR）算法说明 — 公式推导与实例演算

> 生成时间: 2026-08-21
> 对应实现: `fund-tracker-backend/src/main/java/com/fundtracker/service/AnnualizedReturnService.java`
> 实例数据: 纳斯达克100（南方纳斯达克100指数发起(QDII)A，基金代码 016452）

---

## 一、问题：多笔交易无法用"单笔公式"算收益

只有一笔交易时，收益率很好算：`(卖出所得 - 买入成本) / 买入成本`。

但真实持仓往往是**多笔、不同时间、不同金额、含卖出**的现金流组合：
1 月 1 日买 30 元、2 月 2 日买 40 元、3 月 3 日买 30 元、4 月 4 日卖出 50 元——
每笔钱"在场"的时间不同，简单的总额相除会完全扭曲结果。

业界标准解法是 **IRR（Internal Rate of Return，内部收益率 / 金钱加权收益率）**：
把整个持仓看作一个"投资项目"，求一个折现率 `r`，使所有现金流的**现值总和恰好为零**。

---

## 二、公式推导

### 2.1 现金流约定

站在"钱包"的视角（钱出为负、钱进为正）：

| 交易类型 | 现金流 CF | 说明 |
|---|---|---|
| buy 买入 | `-total` | 钱从钱包流出 |
| sell 卖出 | `+total` | 钱回到钱包 |
| reinvest 分红复投 | `0` | 分红本就是收益，再投入不产生新现金流 |
| bonus_share 送股 | `0` | 无现金进出 |
| 终值（最后一笔） | `+当前市值` | 假设"现在全部清算"能拿回的钱 |

### 2.2 时间权重

设首笔交易日期为 `D0`，持有天数 `H = today - D0`，则第 `i` 笔交易的时间权重：

```
t_i = (D_i - D0) / H        ∈ [0, 1]
```

`t_i` 的含义：这笔钱"在场时间占整个持有期的比例"。首笔 `t=0`，终值 `t=1`。

> 注意：程序刻意让 `t ∈ [0,1]`（而不是以"年"为单位），这样解出的 IRR 是**持有期收益率**，
> 再统一换算年化，避免时间权重与年化公式双重放大（历史上曾因此把 31 天小亏虚高成 505%）。

### 2.3 NPV 方程与 IRR 定义

将每笔现金流按 `(1+r)^t_i` 折现回起点，令净现值为零：

```
NPV(r) = Σᵢ  CFᵢ / (1 + r)^tᵢ  =  0
```

- 若 `r > 0`：晚发生的流入折现后仍能覆盖流出 → 盈利
- 若 `r < 0`：折现后入不敷出 → 亏损
- 解出的 `r` 即**持有期收益率**（IRR）

### 2.4 年化换算

```
年化收益率 = (1 + r)^(365 / H) − 1
```

把 H 天的持有期收益率复利外推成一整年的口径，便于不同持有期的标的横向比较。

### 2.5 求解方法：二分法

NPV(r) 在 `r ∈ (-1, +∞)` 上单调递减（流入越多需要的折现率越高），程序在
`[-0.999, 10]` 区间二分，100 次迭代内收敛到 `|NPV| < 0.01`。

---

## 三、程序实现要点（AnnualizedReturnService）

1. 仅对 `us_stock / gold / dividend` 三类持仓计算；
2. 交易按日期升序排列，构建现金流与时间权重数组（见 2.1/2.2）；
3. 二分法解 IRR；
4. **三层保护**，防止输出不可信数字：
   - 持有天数 < 7 或交易笔数 < 2 → 不计算（前端显示"数据不足"）；
   - IRR 不收敛（100 次迭代后 |NPV| > 0.01）→ 返回 `status=abnormal`；
   - 年化超出 `[-95%, 1000%]` → 返回 `status=abnormal`（前端显示"收益波动异常或暂不可信"）。

## 四、实例演算：纳斯达克100（截至 2026-08-21）

### 4.1 交易流水（26 笔买入，无卖出）

| 日期 | 笔数 | 金额(元) | 距首买天数 d | 时间权重 t = d/31 |
|---|---|---|---|---|
| 07-21 | 4 笔(1260.01+10+10+760.06) | 2040.07 | 0 | 0.000 |
| 07-22 ~ 07-24 | 3 × 10 | 30.00 | 1~3 | 0.032~0.097 |
| 07-27 ~ 07-31 | 5 × 10 | 50.00 | 6~10 | 0.194~0.323 |
| 08-03 ~ 08-07 | 5 × 10 | 50.00 | 13~17 | 0.419~0.548 |
| 08-10 ~ 08-14 | 5 × 10 | 50.00 | 20~24 | 0.645~0.774 |
| 08-17 ~ 08-20 | 4 × 10 | 40.00 | 27~30 | 0.871~0.968 |
| **合计** | **26** | **2260.07** | | |

持有天数 H = 2026-07-21 → 2026-08-21 = **31 天**；当前市值 = **2241.62 元**（终值，t=1）。

### 4.2 代入 NPV 方程

```
NPV(r) = -2040.07/(1+r)^0.000  - 10/(1+r)^0.032  - ...  - 10/(1+r)^0.968  + 2241.62/(1+r)^1  =  0
          └─ 首日四笔合计 ─┘      └─ 22 笔定投 ─┘                └─ 末笔买入 ─┘    └─ 终值 ─┘
```

### 4.3 二分求解（过程节选）

| 迭代 | r 区间 | 中点 r | NPV(r) | 动作 |
|---|---|---|---|---|
| 1 | [-0.999, 10] | 4.5005 | 远小于 0 | NPV<0 → 收紧上界 |
| ... | ... | ... | ... | ... |
| 后段 | ≈[-0.009, -0.008] | -0.00858 | ≈ 0 | 收敛 |

解得 **r = -0.8586%**（验证：NPV(-0.008586) = 0.000000）。

### 4.4 结果

| 指标 | 数值 | 说明 |
|---|---|---|
| 持有期收益率 (IRR) | **-0.8586%** | 31 天实际亏了约 0.86% |
| 绝对盈亏 | **-18.45 元** | 2241.62 - 2260.07 |
| 年化收益率 | **(1-0.008586)^(365/31) − 1 = -9.65%** | 与界面显示一致 |

## 五、已知特性：零轴附近的"符号乱跳"

持有期短且盈亏接近打平时，年化的指数放大 `(365/H)` 会把 ±0.8% 的小幅波动放大成 ±10%：
（下表为同一持仓、仅终值变化时的年化，H=31 天）

| 当前市值 | 盈亏(元) | 年化 |
|---|---|---|
| 2230.00 | -30.07 | -15.3% |
| 2241.62（实际） | -18.45 | **-9.7%** |
| 2250.00 | -10.07 | -5.4% |
| 2260.07（打平线） | 0.00 | 0.0% |
| 2270.00 | +9.93 | +5.6% |
| 2280.00 | +19.93 | +11.5% |

即：市值离打平线 ±10 元，年化就翻转一次符号。这是 IRR 年化的数学性质（非 Bug），
持有期拉长后自然回落平滑。三层保护保证极端情况下宁可显示"数据不足/异常"也不输出误导数字。

## 六、与其他口径的区别

| 口径 | 公式 | 用途 |
|---|---|---|
| **IRR 年化**（本文） | 现金流折现 + 年化 | 衡量"这笔投资作为整体"的效率，含时间价值 |
| 收益走势 profit_loss | 当前市值 − cost_basis | 资产历史页的逐日盈亏曲线（快照口径） |
| 资产概览区间收益 | 当前市值 − 期初市值 − 期间净投入 | 发现页"本周/本月/本年"真实收益（v2.4.6 起） |

三者本金口径不同（IRR 用逐笔现金流、快照用 cost_basis、区间用期初反推），
短期打平时符号可能不一致，属正常现象。
